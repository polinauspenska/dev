# LN Hero Experience — WordPress plugin 4.4.10

Install the ZIP through WordPress Plugins > Add New > Upload Plugin; replace the existing LN Hero Experience installation. Insert `[ln_hero]` on a full-width page. Optional ACF fields can configure assets and links. The plugin uses plain JavaScript, CSS and a custom WebGL background; the visible helmet uses an aligned image with a moving CSS mask.

Read UPDATE-4.4.10.md for this release, existing CSS compatibility and validation limits. No live site has been updated by supplying this ZIP. The theme must allow the hero sticky stage to scroll; do not place it within a vertically clipped wrapper.
